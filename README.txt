PORTAFOLIO SAMUEL MONTEALEGRE

Abre index.html en Chrome, Edge o Firefox.

El sitio incluye:
- 21 reportajes enlazados a El País.
- Filtros por tipo.
- Sección multimedia.
- Imagen proporcionada para Cariño Nocturno.
- Botón que abre el Reel de Instagram proporcionado.
- Sección de impresos preparada para PDFs.
- Diseño responsive para celular.

Si tienes los PDFs, colócalos en assets/pdf/ con estos nombres:
joven-medico.pdf
bombas.pdf
estallido.pdf

Si tienes el CV, colócalo como:
assets/CV-Samuel-Montealegre.pdf


V8 — IMPRESO Y CONTACTO
